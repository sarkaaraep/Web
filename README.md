# TNEA Assemble

Avengers + Superstar themed guide to TNEA counselling with a college predictor and a built-in chat assistant.

## Host on GitHub Pages
1. Create a new repository (e.g. `tnea-assemble`) on GitHub.
2. Upload `index.html`, `README.md` and `.nojekyll` to the repo root.
3. Go to Settings > Pages > Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`, then Save.
4. Your site goes live at `https://<your-username>.github.io/tnea-assemble/`.

## Notes
- Single self-contained file; only Google Fonts load externally.
- College cutoffs in `index.html` (the `D` array in the script) are illustrative. Replace them with official TNEA previous-year data.
- Always verify dates, fees and rules at https://www.tneaonline.org
